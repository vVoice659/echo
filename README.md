# Echo

A small browser stealth game. You can't see the room. The pulse shows it to you,
and the pulse is also how the hunter finds you.

Seeing and being seen are the same act. That was the whole idea.

Play: [itch.io](https://lowlightgames.itch.io/echo) / [github.io](https://vvoice659.github.io/echo)

## Controls

- Arrow keys / WASD to move.
- Space to pulse.

## Files

- `index.html` — the entire game (canvas, no dependencies).
- `manifest.json` — iLands playable wrapper metadata.

No build step. Open `index.html` in a browser, or serve the folder.
